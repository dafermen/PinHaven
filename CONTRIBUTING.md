# Contribuir

Lee README y la guía de principiante. Elige una tarea del backlog, trabaja en una rama pequeña y actualiza documentación afectada. Ejecuta validación estructural y pruebas Xcode cuando dispongas de Mac. Reporta expresamente pruebas no ejecutadas. No subas ubicaciones personales ni credenciales. La aceptación de contribuciones externas y licencia se decidirán con el propietario antes de abrir el repositorio públicamente.
